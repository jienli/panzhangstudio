# 张磐 Zhang Pan — painting site

Plain HTML/CSS/JS in `site/`, no build step. Every push to `main` publishes `site/` to
https://panzhangstudio.com via GitHub Pages (`.github/workflows/deploy.yml`).

- **Preview:** `python3 -m http.server 8420 --directory site`, then open http://localhost:8420
- **Edit text:** page wording (both languages) is in `STRINGS` at the top of `site/app.js`;
  painting titles, dates and notes are in `site/works.js`.
- **Contact email:** `SITE.contactEmail` in `site/works.js` (empty hides the contact links).

## Adding paintings

Source photos live in `photos/` (kept off GitHub). Each painting is listed in
`tools/images.json` with its photo, rotation and crop.

1. Add the photo to `photos/` and an entry to `tools/images.json`.
2. `.venv/bin/python tools/prepare.py <id>` writes `site/images/<id>.jpg` and `<id>-sm.jpg`.
3. Add an entry to `WORKS` in `site/works.js`.

`prepare.py` evens out the lighting and fold shading of unmounted paper and sets the paper
to warm white (`tools/flatten.py`). It's deterministic: nothing is painted in. A painting can
use gentler settings (`strength`, `detail`, `crease`) when full correction would affect the
painting itself, as with `trees-on-rock`.

One-time setup: `python3 -m venv .venv && .venv/bin/pip install -r tools/requirements.txt`.

## Framing

The gallery draws a walnut frame and bevelled mat around each plain image (`.framed` in
`site/styles.css`). Wood and mat textures are generated by `tools/textures.py`.
`design/framing.html` also keeps a hanging-scroll (立轴) style that isn't used on the site.
